Setup

Up and running
in three steps.

You need a Windows PC with TallyPrime or Tally ERP 9, and a smartphone for the mobile app.

Step 1

Install TallyFin Desktop Agent

Download the Windows installer from our website. Run the setup wizard and sign in with your email — or create a new account. The agent runs in the background on the same machine as Tally.

Download for Windows

Step 2

Connect Tally & add companies

  1. Ensure TallyPrime or Tally ERP 9 is installed and companies are accessible.
  2. In Tally, enable ODBC / sync as per the in-app guide (shown on first launch).
  3. Open each company in Tally, then click Add company in the desktop agent.
  4. Choose what to sync: masters, vouchers, stock — and run your first sync.

Step 3

Install the mobile app

Download TallyFin from the Play Store (iOS coming soon). Log in with the same email and password you used on the desktop agent. Select a company and explore your synced data — works offline after sync.
